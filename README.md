# Alek’s Birdhouse Project

Alek Andriejunas’s existing Year 8 Technology Mandatory project, 2026. The five-page design, images, measurements and 20 construction steps are preserved.

- Website: https://alekandriejunasphone-byte.github.io/alek-birdhouse-website/
- Repository: https://github.com/alekandriejunasphone-byte/alek-birdhouse-website
- Deployment: GitHub Pages through the manual `Deploy static birdhouse website` Actions workflow.

## Google Sites

Choose **Pages → + → Full page embed**, name the page, and paste the website URL above. Do not use the old large HTML snippets. See `GOOGLE_SITES_OPTION_2.md` for the exact link and fallback button.

## Edit and preview

Edit `src/pages/`, `assets/styles.css`, `assets/app.js` or `src/photos.json`, then run:

```sh
python3 build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/ on your Mac; Control-C stops the server. This local preview address is not the published website URL. Root HTML pages are generated by the builder. Photo replacement instructions and source licences are in `IMAGE_REPLACEMENT.md` and `IMAGE_CREDITS.md`.

## Publish future changes

Commit and push the updated files, then choose **Actions → Deploy static birdhouse website → Run workflow → main → Run workflow** in the repository. Uploads alone do not deploy. Wait for success before checking the public URL.

`index.html` is Home; `project.html`, `construction.html`, `birds.html` and `about.html` are the other four pages. Four old URLs remain as redirects. The workflow excludes local test pages and the preserved legacy HTML embed files.

See `TEST_REPORT.md` for checks performed and their limits. The original teacher handout and personal project photos were not supplied; placeholders and notes about missing dimensions remain.
